# Starcraft II Archipelago Client AI Usage Disclosure
The Starcraft II Archipelago Client does not make use of code or art created by generative AI/LLMs. Explicitly:
- no code was generated (vibe-coded) or modified by AI tools
- no art was generated or modified by AI tools
- no auto-completion or AI coding assistants were used (copilot)
- no documents or comments were generated by AI tools
  - some documents are auto-generated, but explicitly without AI assistance

The current maintainers do share a moderate anti-AI stance. Contributors are encouraged to refrain from using generative AI tools for code or art submissions. If generative AI has been utilized for any 3rd party submissions, proper disclosure to the maintainers is required.
